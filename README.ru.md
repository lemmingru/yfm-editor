# YFM Editor — краткая инструкция

[English](README.md) | **Русский**

Версия **0.4.0** · [История изменений](CHANGELOG.md)

Это памятка для тех, кто просто хочет пользоваться редактором: установка, снятие
карантина macOS, горячие клавиши и настройки. Полная документация (разработка,
тесты, устройство проекта) есть только в [английском README](README.md) — он же
считается основным, поэтому при расхождениях верно то, что написано там.

YFM Editor — редактор Markdown-файлов в формате
[YFM](https://ydocs.tech) (Yandex Flavored Markdown) для macOS. Понимает
многострочные таблицы, `{% cut %}`, `{% note %}`, табы, файлы, LaTeX и Mermaid.
Интерфейс — русский или английский, по умолчанию берётся язык системы.

## Установка готовой сборки

Если вам передали `.dmg` или готовый `YFM Editor.app`:

1. Откройте `.dmg` и перетащите **YFM Editor** в папку «Программы».
2. Выполните в Терминале:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/YFM Editor.app"
   ```

3. Запустите приложение обычным двойным щелчком.

Второй шаг обязателен. Приложение собрано без подписи Apple Developer ID и не
проходило нотаризацию, а macOS помечает всё скачанное или принесённое с другого
компьютера атрибутом `com.apple.quarantine`. Без снятия атрибута Gatekeeper
откажется открывать приложение и сообщит, что программа повреждена либо что не
удалось проверить разработчика. Команда снимает проверку только для одного
приложения, поэтому запускайте её лишь для сборки, которой доверяете.

Повторяйте шаг 2 после установки каждой новой версии: атрибут появляется вместе с
новым скачанным файлом.

Если Терминала под рукой нет, можно один раз запустить приложение вручную:
щёлкните по нему правой кнопкой → **Открыть** → в диалоге ещё раз **Открыть**.
На свежих версиях macOS вместо диалога появляется кнопка **«Всё равно открыть»** в
Системных настройках → «Конфиденциальность и безопасность».

## Сделать редактором `.md` по умолчанию

В Finder щёлкните правой кнопкой по любому `.md`-файлу → **Свойства** (⌘I) →
раздел «Открывать в программе» → выберите **YFM Editor** → **Настроить…**, чтобы
применить ко всем таким файлам. Приложение регистрируется как редактор для `.md`,
`.markdown` и `.mdx`.

## Сборка из исходников

Нужны Node.js 24 LTS, npm 11.5.1 или новее, Rust 1.90 или новее (через `rustup`) и Xcode Command Line Tools.
Команда `nvm use` выбирает версию Node.js из `.nvmrc`.

```bash
git clone https://github.com/lemmingru/yfm-editor
cd yfm-editor
npm install
npm run app:build
```

Готовая сборка появится в `packages/desktop/src-tauri/target/release/bundle/`:
приложение — в `macos/YFM Editor.app`, образ для установки — в `dmg/`. Приложение,
запущенное прямо из этой папки, обычно не в карантине, и `xattr` не нужен.

Если сборка сообщает `Cargo was not found`, установите Rust, перезапустите
терминал и попробуйте снова:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"
xcode-select --install
```

Для разработки с горячей перезагрузкой интерфейса используйте `npm run app`.

## Как пользоваться

- **Файл**: «Новый» (⌘N), «Открыть…» (⌘O), «Открыть недавние», «Сохранить» (⌘S),
  «Сохранить как…» (⇧⌘S), «Вернуть к сохранённому».
- **Вид**: «Переключить тему» (⇧⌘L) и «Проверка орфографии» — системная проверка
  орфографии, включена по умолчанию.
- **Правка ▸ Копировать контекст для агента** (⌥⌘C) — копирует в буфер
  `путь:строка` (или `путь:начало-конец`) и выделенный фрагмент разметки. Удобно
  вставлять в чат с ИИ-агентом. В визуальном режиме сопоставить выделение с
  исходной разметкой удаётся не всегда; тогда приложение просит переключиться в
  режим разметки.
- **Настройки…** (⌘,) — тема, язык интерфейса, режим редактора по умолчанию,
  открывать документ в новом или в текущем окне, проверка орфографии.
- Режимы работы: визуальный WYSIWYG (по умолчанию), режим разметки Markdown и
  предпросмотр рядом с текстом — переключаются на панели инструментов редактора.
- Кнопка боковой панели слева на панели инструментов открывает **структуру
  документа**. Заголовки позволяют переходить к разделам в визуальном режиме и
  в Markdown; подразделы можно сворачивать. Панель изначально скрыта, её состояние
  запоминается для каждого файла. Также доступна команда **Вид ▸ Структура
  документа** (⌥⌘O). В узком окне панель открывается поверх текста и закрывается
  после перехода.
- Каждый документ живёт в своём окне; по умолчанию открытие файла создаёт новое
  окно, это меняется в настройках.
- Несохранённые изменения видны по `*` в заголовке окна и по точке в кнопке
  закрытия. Перед потерей таких правок приложение всегда спрашивает подтверждение.
- Двойной щелчок по `.md` в Finder открывает файл в редакторе.

## Если что-то пошло не так

- **«Программа повреждена» или «не удалось проверить разработчика»** — не снят
  карантин, выполните команду `xattr` из раздела про установку.
- **`Cargo was not found` при сборке** — не установлен Rust, см. раздел про сборку.
- **«Файл изменён на диске. У вас есть несохранённые правки.»** — файл поменяли в
  другой программе. «Отбросить и загрузить» подтянет версию с диска, «Редактировать
  мою версию» оставит ваши правки; при сохранении редактор ещё раз спросит,
  перезаписывать ли диск.
